## Method

1. Choose Remotion only when the scene is React components, not a one-off HTML capture.
2. Define duration, fps, and size before animating.
3. Drive motion from frame index, not from wall-clock timers.
4. Render locally. Do not add a second video framework beside an existing one without a reason.
5. This is not the archived remotion-dev/skills bundle.
