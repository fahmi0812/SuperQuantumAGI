## Method

1. Do not patch first. Finish inspection with reverse-skill or rea.
2. State the byte-level change, the file it touches, and how to revert it.
3. Keep a copy of the original artifact outside the patched output.
4. Refuse patches whose purpose is unauthorized access or concealment of malware.
5. This file is a methodology pointer, not upstream code.
