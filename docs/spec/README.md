# Spec templates (SQAGI)

Adapted from [github/spec-kit](https://github.com/github/spec-kit) `67e0f7294e6e728ab60bf7b4590deb470448bc2d` (MIT). Local templates only. The Specify CLI is not vendored.

| File | Isi |
|------|-----|
| [prd.md](./prd.md) | PRD / feature spec: skenario, FR, kriteria sukses |
| [tech.md](./tech.md) | Konteks teknis + gate konstitusi SQAGI |
| [plan.md](./plan.md) | Rencana implementasi ber-task, siap done-gate |

Isi template di `.scratch/<fitur>/` atau cabang `wave/…`. Jangan commit dump CLI. `to-spec` / `writing-plans` memakai bentuk ini.
